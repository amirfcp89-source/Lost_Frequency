# Lost Frequency — سایت دانلود آهنگ

## این پروژه چیه؟
یه سایت واقعی (نه فقط ظاهری) با:
- صفحه‌ی اصلی: جستجو، فیلتر دسته‌بندی، پخش‌کننده، دانلود واقعی فایل
- پنل مدیریت (`/admin.html`): ورود با رمز، آپلود آهنگ جدید، حذف آهنگ
- دیتابیس SQLite (فایل کوچیک، نیازی به سرور جدا نداره)
- دو جای آماده برای تبلیغات (کد AdSense یا هر شبکه‌ی دیگه رو جاش بذار)

## اجرا روی سیستم خودت (برای تست)
```
npm install
npm start
```
بعد برو به `http://localhost:3000`

رمز پیش‌فرض پنل ادمین: `change-me-123` — **حتماً قبل از انتشار عوضش کن.**

## چطور رمز ادمین رو عوض کنم؟
موقع اجرا این متغیر محیطی رو ست کن:
```
ADMIN_PASSWORD=رمز-جدید-من npm start
```

## چطور آنلاینش کنم؟
این یه اپ Node.js هست، پس نمی‌شه مثل یه فایل HTML ساده آپلودش کرد روی هر هاستی. گزینه‌های ساده:
1. **Railway.app** یا **Render.com** — رایگان یا ارزون شروع می‌کنن، فقط پروژه رو از گیت‌هاب وصل می‌کنی و دکمه‌ی دیپلوی رو می‌زنی.
2. یه **VPS** (مثل سرورهای ایرانی یا خارجی) — با Node.js نصب می‌کنی و با `pm2` روشن نگهش می‌داری.

نکته مهم: فضای دیسک هاست رو در نظر بگیر، چون فایل‌های mp3 حجم می‌گیرن.

## بعداً چی می‌شه اضافه کرد؟
- دامنه‌ی اختصاصی (مثلاً ava-music.ir)
- CDN برای پخش سریع‌تر فایل‌های صوتی
- اگه بعداً خواستی از کاربرا هم پول بگیری (اشتراک/پرداخت به‌ازای دانلود)، باید یه درگاه پرداخت ایرانی (مثل زرین‌پال) بهش وصل بشه — کاملاً جدا از چیزی که الان ساختیم

## یادآوری قانونی
چون آهنگ‌ها با اجازه‌ی هنرمندهاست، مدرک اون اجازه (پیام، ایمیل، قرارداد) رو یه جای امن نگه دار؛ شبکه‌های تبلیغاتی و هاستینگ گاهی موقع گزارش تخلف ازش می‌پرسن.
